# Bisnis Rapi Landing Page

**Bisnis Rapi** adalah agensi transformasi digital yang berfokus pada pembuatan sistem operasional yang rapi, efisien, dan scalable untuk bisnis UMKM dan perusahaan yang sedang berkembang.

## 🚀 Vision
Mentransformasi bisnis konvensional menjadi bisnis digital yang terorganisir melalui sistem dashboard kustom, otomatisasi tugas repetitif, dan kontrol inventori real-time.

## 🛠 Tech Stack
- **Framework:** [Next.js 15+](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Components:** [Shadcn UI](https://ui.shadcn.com/) (Radix Primitives)
- **Deployment:** [Vercel](https://vercel.com/)

## 📂 Project Structure
- `/app`: Next.js App Router pages and layouts.
- `/components`: Reusable UI components.
  - `/landing`: Specific sections for the landing page (Hero, Problem, Solution, etc.)
  - `/ui`: Base primitive components from shadcn.
- `/styles`: Global CSS and Tailwind configuration.
- `/public`: Static assets (images, logos).

## 🏃 Getting Started

### Prerequisites
- Node.js 20+
- npm / pnpm

### Installation
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

### Development
Run the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build
Generate a production-ready build:
```bash
npm run build
```
